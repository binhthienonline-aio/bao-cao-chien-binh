# Báo cáo chiến binh — MVP
## Chạy local
Cài Python 3.10+, Tesseract OCR (ngôn ngữ Vietnamese `vie` và English `eng`), sau đó:
```bash
pip install -r requirements.txt
streamlit run app.py
```
## Deploy miễn phí
1. Tạo GitHub repository và upload các file trong thư mục này.
2. Vào https://share.streamlit.io/ và đăng nhập GitHub.
3. Chọn repository, branch `main`, main file `app.py`, bấm Deploy.
4. Nhận URL dạng `https://ten-app.streamlit.app`.
## Google Drive
Dùng link ZIP công khai hoặc link thư mục công khai. Quyền chia sẻ: “Bất kỳ ai có đường liên kết”.
## Giới hạn MVP
OCR đọc nội dung và dò mã nhân viên, nhưng chưa tự ghép mọi tỷ lệ vào tên nhóm hàng. Bảng dữ liệu chuẩn cần được rà soát/nhập trước khi xuất. Không tự đoán số liệu. Không lưu lịch sử lâu dài. Không nhập link Drive riêng tư.
